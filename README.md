## 🔭 Currently Working On

### [DevJourney](https://github.com/Jafarli-Mahammad/DevJourney) — Backend Developer
A platform for running **competitions and hackathons**. Currently in active development.

**The product:**
- **Participants** join competitions, create or join teams, build projects, and submit them
- **Organizers** create competitions, manage participants and teams, and oversee submissions
- **Judges & Partners** evaluate submitted projects and score them

**The flow:** Competition → Register → Form Team → Build → Submit → Evaluate → Leaderboard

**My role:** Building the entire backend — user management, competition lifecycle, team formation, submission handling, and the organizer dashboard. Working alongside a frontend developer to connect the full end-to-end experience.

**Stack:** .NET, Clean Architecture, EF Core, SQL Server, Docker
